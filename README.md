作成: 2026-11-09（v2 の後継。ビジュアル刷新＋グローバルナビの視認性改善）

## v2 → v3 の変更点
- ヘッダーを濃紺バーに変更し、グローバルナビ（ホーム／サービス▾／料金／ブログ／進め方／FAQ／運営者／[無料診断]）を常時視認できる形に。プルダウンはホバー＋クリック両対応、スマホは全項目を展開表示
- 写真（AI生成・イメージ表記あり）をヒーローと入口カードに導入し、制作会社らしいビジュアルに刷新。画像は base64 で assets/img.css に埋め込み（外部依存なし）
- ブログに本文記事1本を追加（blog/homepage-3points/）。一覧には今後のテーマ5本を掲載
- SNSページにスマホ型の投稿モックを追加

## 構成
```

```
