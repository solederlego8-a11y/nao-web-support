## GitHub Pages への公開手順
1. GitHub で新規リポジトリを作成（例：`nao-web-support`、Public）
2. このフォルダの中身をそのままリポジトリ直下にアップロード（`index.html` が直下に来ること）
3. リポジトリ Settings → Pages → Source を「Deploy from a branch」、Branch は `main` / `(root)` を選択
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される
5. 公開後に確認すること：全ページの表示、サービスプルダウン、スマホ表示、無料診断フォームの送信テスト（FormSubmit は初回に確認メールが届く場合がある）

※ Muse 経由でリポジトリ作成・ push する場合は、GitHub App のリポジトリ選択（インストール先の許可）が別途必要。2026-11-09 時点では未完了のため、このフォルダを渡して手動アップロードでも公開できる形にしてある。
